# 代码图谱与全局记忆

- 创建时间: 2026-09-05 20:27

> 代码图谱目前是实验性功能，界面、数据结构和索引行为都可能在后续版本中调整。

代码图谱使用 CodeGraph 分析项目中的符号和关系。全局记忆保存设计决策、约束和经验；两者通过代码引用关联，分别提供当前代码结构与历史设计背景。

## 启用项目索引

1. 在左侧项目或集合的右键菜单中选择“代码图谱”。
2. 首次使用时选择“下载 CodeGraph”。当前连接的后端从 GitHub 下载固定的 1.6.0 版本，并核对内置 SHA-256 校验值。无需另行安装 Node.js。
3. 选择工作目录，再选择“启用索引”。项目目录以及会话、分组关联的其他工作目录分别列出；Git worktree 使用独立索引。集合需要先有带有效工作目录的会话。
4. 等待状态变为“可用”，即可搜索符号或文件路径。初始化在后台执行，关闭界面不会取消任务。

“同步索引”用于手动更新或重试。查询代码前也会执行增量同步，没有打开界面时不需要保持文件监视进程运行。停用会停止正在执行的索引任务，并保留索引文件和记忆关联；之后可以重新启用。任务中断后，过期的运行状态会在读取列表时转为可重试的失败状态，最长约两分钟。单次索引任务上限为 30 分钟。

索引存放于各工作目录的 `.codegraph/` 中，由 CodeGraph 管理。VelaTerm 通过 SDK 执行索引，不调用上游的 Agent 安装程序，也不安装 Git hooks。项目根目录若是仓库中的子目录，只索引所选择的目录，不自动扩大到整个仓库。

## 查看代码关系

搜索结果列出符号名称、类型和位置。打开符号后，可查看源码、传入关系、传出关系和相关记忆；点击相邻符号继续浏览。

关系来自静态分析，可能不完整或存在不确定性，不能代替运行验证。页面最多展示每个方向 200 条关系、600 行符号源码；超出时会提示。源文件超过 4 MiB 时不展示内容。查询期间文件变化会显示提示，此时应重新同步。

项目、工作目录、符号、关联编辑界面，以及搜索和分页都有独立 URL。可以复制链接、刷新页面、在新标签页打开，或使用浏览器前进和后退。链接需要在同一个后端及有效登录状态下访问。

## 关联与复核记忆

在符号详情中选择“关联记忆”，选取已有记忆并核对正文与源码，然后保存。记忆详情中的“代码引用”可以返回对应代码；图谱中的记忆链接可以打开完整记忆。

关联保存的是项目、工作目录、文件路径、符号身份及已复核文件的 SHA-256 摘要。文件变化后会提示“需要复核”；文件不可读或已删除时显示“不可用”。这是文件级提示，同一文件中的其他代码变化也会触发复核。记忆详情打开时会定期检查这些引用。

选择“核对代码与记忆”查看当前内容，确认无误后选择“确认已复核”。后端会再次检查所显示的文件摘要和记忆版本；操作期间发生变化时要求重新加载。复核仅更新代码引用，不修改记忆正文。需要修改结论时，使用记忆条目原有的编辑功能。

符号被删除或重命名后，不会自动关联到同名的其他符号。可以移除旧关联，再为合适的符号建立关联。删除记忆会移除其关联；删除项目会移除其索引管理记录和关联，不删除其他记忆或工作目录中的索引文件。

## 会话内查询

VelaTerm 启动的终端与 Agent 会话均提供 `vknowledge` 命令。现有会话若未包含更新后的命令，需要重新启动会话进程。启用应用的内置技能后，Claude 和 Codex 也会获得配套说明；其他能运行终端命令的 Agent 可以使用同一命令。

```sh
vknowledge status
vknowledge search "greet"
vknowledge node "搜索结果中的符号 ID"
vknowledge memories "设计决策"
vknowledge memory "搜索结果中的记忆 ID"
```

`search` 分别返回代码搜索结果和全局记忆摘要；`node` 返回精确符号的源码、关系和关联记忆；`memory` 返回记忆正文、来源、修订信息与代码引用。代码查询按命令执行时的实际工作目录选择索引，子目录可使用所属项目的索引，嵌套的独立 worktree 不会借用主工作区索引。

索引未启用或查询失败时，结果明确给出代码不可用状态，仍可查询全局记忆。这些命令不会安装运行时、启用索引或修改记忆。

## 本地、远程与数据位置

运行时安装于应用数据目录的 `codegraph/1.6.0/`；任务状态和记忆引用位于应用数据库的 `knowledge_*` 表中。索引在代码所在后端执行，浏览器和 SSH 连接通过现有后端通信读取结果，无需新增图谱服务端口。不同后端分别保存索引配置和全局记忆。

运行时的遥测、更新检查和独立守护进程均关闭。索引计算本身不调用 AI；Agent 查询得到的代码或记忆可能进入其已配置的模型服务，数据处理方式与普通 Agent 读取源码相同。

日志默认位于应用数据目录的 `logs/knowledge.log`。可用 `VLX_KNOWLEDGE_LOG_DIR` 指定目录，或用 `VLX_KNOWLEDGE_LOG_LEVEL=error` / `off` 限制日志。日志不包含源码、查询文本、记忆正文或认证信息。
