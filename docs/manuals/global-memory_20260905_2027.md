# 全局记忆

- 创建时间: 2026-09-05 20:27

> 全局记忆目前是实验性功能，界面、数据结构和整理流程都可能在后续版本中调整。

全局记忆使用 LLM Wiki 的组织方式，将多个会话中的知识、决策、约束和经验整理为持续维护的主题条目。它属于当前连接的应用后端，跨项目和会话共享；连接其他服务器时，查看的是该服务器的全局记忆。

它与会话内容搜索相互独立。会话搜索用于查找原始对话，全局记忆检索只查询已保存的记忆条目。当前功能提供主动加入、主题合并、查阅和维护，不会自动向新会话注入记忆。

## 从会话加入

1. 在侧边栏或会话标签的右键菜单中选择“加入到全局记忆”。归档列表也提供同名入口。
2. 在对话框中选择 Claude 或 Codex。程序使用“设置 → 智能体”中的可执行文件路径；未配置时从已安装程序和 PATH 中查找。
3. 从下拉列表选择模型和思考程度，或保留默认配置。思考程度按所选模型支持的档位显示；选择默认模型或模型未提供档位时，思考程度沿用 CLI 配置。Codex 模型列表由本机 CLI 查询，Claude 复用后端模型目录及已配置的模型。列表读取失败时可以重试。CLI 需要具备有效登录状态及可用模型。
4. 选择“整理并保存”。所选智能体将接收此会话的文字及相关记忆，通过其已有模型服务配置完成整理。
5. 在“整理记录”中查看进度、打开结果或来源。关闭窗口不会停止后台任务，可以主动取消正在运行的任务；失败或中断的任务可以重试，重试保留原来的模型和思考程度。整理记录显示任务选择的配置；默认选项表示由 CLI 决定，不代表已经解析出具体模型或档位。

程序优先读取已有的智能体转录。没有可读转录时，使用该会话已经保存的终端录制，去除终端控制序列。两种来源都不可读时，会明确提示没有可读取的会话内容。终端录制保留的是可见屏幕文本，可能包含重绘内容；整理时不能将这类输出当作经过验证的结论。

来源快照保存整理当时读取的文字。会话继续发展后，再次加入会生成新的来源快照；在智能体、模型和思考程度选择相同的情况下，完全相同且已成功整理的来源会打开已有结果，避免重复调用；更换智能体、模型或思考程度后可重新整理。

## 主题整理与关联

整理分为三个阶段：

- **提取主题**：分段读取会话，提取可复用知识，将主题与现有条目目录匹配。新主题也会进入当前任务目录，供后续片段匹配。
- **合并知识**：逐个主题整合新内容和已有完整条目，保留仍然成立的知识、约束与不确定性。提示词要求明确处理后续修正和矛盾，不自行编造结论。
- **保存记忆**：后端校验字段、来源、关联和版本，并在单个数据库事务内保存全部结果及修订记录。任何校验失败或版本冲突均不会写入部分记忆条目。

智能体返回结构化内容，由程序负责数据库操作。记忆条目通过关联列表相互连接，反向引用自动计算。来源快照与修订历史不依赖原会话继续存在。

智能体整理仍需要人工判断内容质量。发现不准确之处，可以直接编辑条目，或从修订历史恢复旧版本；恢复会产生新修订，保留操作前的版本。

## 查阅与维护

“设置”右侧的“全局记忆”入口打开主题浏览界面。

- 检索标题、摘要、正文和标签，支持中文及多个关键词；关键词之间采用 AND 条件。
- 用标签筛选，按最近更新或标题排序。列表按每页 40 条分页。
- 打开条目后，查看 Markdown 正文、关联记忆、引用该条目的记忆、来源和修订历史。
- 支持手动新建、编辑、删除，以及导出单篇 Markdown。删除条目会一并删除其修订历史，但不删除来源会话和已保存的来源快照。
- 条目详情、编辑页、来源快照、历史版本、整理对话框和任务记录都有独立 URL。搜索、筛选、排序和分页也记录在 URL 中。

## 数据与运行约束

所有权威数据位于应用现有 SQLite 数据库的 `memory_*` 表中，独立于 `session_fts` 等会话搜索索引。前端仅保存展示及尚未提交的表单状态，最终校验、版本检查、重复检测和写入都在后端完成。

同一数据库一次运行一个整理任务。人工编辑可以同时进行；如果编辑了正在合并的条目，整理任务会报告版本冲突，保留人工修改，随后可以重试。

当前单个来源上限为 2,000,000 个字符；每段提取最多 24,000 个字符；单次模型输入上限为 350,000 个字符；单条正文上限为 200,000 个字符。单次 CLI 调用限时 10 分钟，输出流上限各为 8 MiB。超限会明确失败，不截断后继续入库。

运行中的任务定期更新心跳；连续两分钟没有心跳的任务在再次读取任务列表或启动任务时标为中断，可使用保存的来源快照重试。取消任务不会删除来源快照。

运行日志默认位于应用数据目录的 `logs/memory.log`，可用 `VLX_MEMORY_LOG_DIR` 覆盖；`VLX_MEMORY_LOG_LEVEL=error` 只记录错误，`off` 关闭本模块日志。日志记录任务及步骤、输入输出数量、耗时、字符数、SHA-256 和数字 Token 用量，不记录完整提示词、来源文本、模型响应、认证信息或 stderr 内容。原始证据在来源快照中查阅。

## 与代码图谱关联

记忆条目可关联项目代码符号，并从“代码引用”跳转到图谱。代码文件变化后显示复核提示；确认复核不会改写记忆正文。会话中的 Agent 也可以通过 `vknowledge` 按需查询代码和记忆。具体操作见[代码图谱与全局记忆](codegraph_20260905_2027.md)。
